# Система мониторинга воздушных объектов по обращениям 112 (Python + Ollama LLM + OpenStreetMap)

Демонстрационный прототип для магистерской диссертации.

## Архитектура и принцип работы
1. **Ввод обращения**: Оператор 112 (или вы на демонстрации) вводит текст сообщения о замеченном беспилотнике в текстовое окно на сайте.
2. **Обработка в локальной LLM (Ollama)**: Python-сервер (`server.py` -> `llm_client.py`) отправляет текст в локальную модель Ollama (`http://localhost:11434/api/chat`).
3. **Приведение к именительному падежу и извлечение ролей**: LLM извлекает из произвольного текста:
   - `settlement_seen` — населённый пункт, где заметили объект (в **именительном падеже**);
   - `district` — муниципальный район (для разрешения омонимии одноимённых деревень);
   - `direction_to` / `direction_compass` — ориентир или сторону света, куда летит объект (в **именительном падеже**);
   - `event_time` — время сообщения.
4. **Сопоставление со справочником (`geocoder.py` + `settlments.csv`)**: Алгоритм ищет населённый пункт в справочнике Республики Башкортостан (`settlments.csv`, 4 561 НП), берёт его широту и долготу и рассчитывает вектор движения.
5. **Отображение на веб-карте (`index.html`, Leaflet + OpenStreetMap)**:
   - На карте ставится пульсирующая метка и строится пунктирный вектор направления полёта.
   - При нажатии на точку открывается **карточка**, в которой указаны **время сообщения**, **полный текст сообщения**, **населённый пункт / район** и **направление движения**.

## Быстрый запуск на вашем компьютере

Никаких внешних библиотек (`pip install`) устанавливать **не нужно** — весь сервер написан на стандартной библиотеке Python 3, чтобы запуск прошёл без единой ошибки.

### Шаг 1. Проверьте, что запущена Ollama
Убедитесь, что у вас запущена программа **Ollama** и скачана хотя бы одна модель (например, `llama3.2`, `qwen2.5:7b` или `mistral`):
```bash
ollama list
```
*(Если список пуст, скачайте любую лёгкую модель: `ollama pull llama3.2` или `ollama pull qwen2.5:7b`).*

### Шаг 2. Запустите сервер системы
Откройте терминал (или командную строку) в распакованной папке и выполните:
```bash
python server.py
```
*(На Windows можно просто дважды кликнуть по файлу `start_windows.bat`).*

### Шаг 3. Откройте веб-приложение
Перейдите в браузере по адресу:
**http://localhost:8000**

В левой панели выберите вашу модель Ollama (система определяет установленные модели автоматически), введите любое сообщение или нажмите на одну из кнопок **«Быстрые примеры для демонстрации»** и нажмите **«Обработать через LLM и отметить на карте»**.

## Как выложить проект на GitHub и включить сайт (GitHub Pages)

### Вариант А. Выложить код в репозиторий GitHub (и запускать через `python server.py`)
1. Зайдите на [github.com](https://github.com) и нажмите **New repository** (кнопка `+` в правом верхнем углу).
2. Назовите репозиторий, например: `uav-monitoring-112`, выберите **Public** и нажмите **Create repository**.
3. Откройте терминал в папке с распакованным проектом и выполните команды:
```bash
git init
git add .
git commit -m "Прототип системы мониторинга воздушных объектов (112 + Ollama + OSM)"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/uav-monitoring-112.git
git push -u origin main
```

### Вариант Б. Включить GitHub Pages (чтобы сайт открывался по прямой веб-ссылке)
В проекте реализован двойной режим: если открыть `index.html` через **GitHub Pages**, сайт сам загрузит `settlments.csv` в браузер и сможет обращаться напрямую к вашей локальной Ollama на `http://localhost:11434`.

1. В вашем репозитории на GitHub перейдите во вкладку **Settings** -> в меню слева выберите **Pages**.
2. В разделе **Build and deployment** -> **Branch** выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
3. Через 1–2 минуты сверху появится ваша ссылка вида:
   `https://ВАШ_ЛОГИН.github.io/uav-monitoring-112/`
4. **Важно для связи сайта GitHub Pages с локальной Ollama**: чтобы браузер разрешил сайту с `github.io` отправлять запросы на ваш локальный `localhost:11434`, перед запуском Ollama задайте переменную окружения `OLLAMA_ORIGINS="*"`:
   - **Windows (PowerShell)**:
     ```powershell
     $env:OLLAMA_ORIGINS="*"; ollama serve
     ```
   - **macOS / Linux**:
     ```bash
     OLLAMA_ORIGINS="*" ollama serve
     ```
   *(Даже если Ollama не запущена, сайт на GitHub Pages автоматически переключится на встроенный морфологический анализатор и всё равно поставит точки на карту по справочнику `settlments.csv`).*
